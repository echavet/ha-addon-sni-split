# Relais par nom

Module Home Assistant. Il écoute le port 443, lit le nom demandé dans le premier message chiffré, et transmet la connexion sans la déchiffrer.

Les cibles se règlent dans l'onglet Configuration du module.

Dépôt à ajouter dans le magasin des modules :

```
https://github.com/echavet/ha-addon-sni-split
```
